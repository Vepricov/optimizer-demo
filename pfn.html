PFN · Prior-data Fitted Network

Модель училась заранее.
Для старта достаточно немного разметки.

PFN — предобученная модель для прогнозирования по таблицам и графам. Она переносит опыт множества задач на вашу: для первого пилота может быть достаточно небольшого количества качественно размеченных примеров. В режиме in-context learning они задают контекст, а веса модели остаются фиксированными.

01 / ПРЕДОБУЧЕНИЕ

Опыт множества задач

Модель заранее решает разнообразные синтетические задачи и учится находить закономерности между признаками и ответами.

02 / ВАША ЭКСПЕРТИЗА
Пример 1 ✓Пример 2 ✓Новый объект ?

Небольшой набор разметки

Эксперт проверяет опорные примеры вашей задачи. Модель получает их как контекст и прогнозирует ответы для новых объектов — можно начать до накопления большого размеченного датасета.

03 / ПЕРВЫЙ ПИЛОТ
Данные → PFN → Прогноз

Быстрый старт

В базовом режиме можно начать без обучения весов под каждую задачу. Дообучение помогает в отдельных сценариях — например, при категоризации товаров.

Начните с качества примеров

Небольшой объём разметки снижает порог старта. Согласуйте критерии, перепроверьте спорные ответы, включите редкие случаи. Нужный объём зависит от задачи; качество пилота проверяют на отдельных данных.
